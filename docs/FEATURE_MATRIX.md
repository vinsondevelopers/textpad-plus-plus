## Scintilla key commands (upstream `scintKeyDefs`)

Editing/navigation commands executed by Scintilla itself. In the macOS shortcut scheme Textpad++ keeps Scintilla Cocoa's native macOS keys (e.g. ⌘← line start, ⌥← word left); in the Windows scheme it assigns the upstream keys below with Ctrl = Control (SCI_ASSIGNCMDKEY, `src/commands/ScintillaKeys.mm`). Every key can be changed in Settings > Shortcut Mapper > Scintilla commands and is saved in shortcuts.xml <ScintillaKeys> (T-KEYS-003).
